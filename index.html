FAQ

Is SiteSucker safe for all sites?

Yes. It respects robots.txt by default and downloads only publicly accessible content. Always check site terms.

Can I pause or resume downloads?

Downloads pause automatically on errors and resume where left off. Manual pause/resume available.

What file types does it handle?

HTML, CSS, JS, images, videos, PDFs, and more. Exclude or include specifics as needed.

Does it work with modern sites?

Fully supports dynamic content, SPAs, and large sites. Handles redirects and relative links precisely.
